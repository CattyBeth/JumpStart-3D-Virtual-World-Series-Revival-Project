# Tools

This directory contains tools and scripts used to investigate,
extract, test, or document supported games.

## Planned/Investigated Tools

| Tool | Purpose | Platform | Status |
|---|---|---|---|
| Unshield | Extract InstallShield archives | Windows/Linux | Testing |
| dumpbin | Examine PE imports | Windows | Investigating |
| Protontricks | Manage Wine/Proton dependencies | Linux | Testing |
| Procmon | Monitor Windows file/registry activity | Windows | Testing |
| Wine/Proton logging | Investigate runtime behavior | Linux | Testing |

## Guidelines

Tools should be documented before being added to the repository.

Do not commit third-party binaries unless their license permits
redistribution and the project explicitly intends to distribute them.

Prefer documenting how contributors can obtain/build the tool.
