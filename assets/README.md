# Assets

This directory is reserved for game assets used during development
and testing.

## Important

Do not commit complete copies of game installation media or extracted
game installations without confirming that redistribution is permitted
by the applicable game license.

Large binary assets should not be committed to the repository simply
for convenience.

Instead, document:

- Original filename
- Location
- File type
- Size
- Hash, if useful
- Extraction method
- Conversion method
- License/redistribution status
