**For Windows 10/11:**  
  Install JumpStart World Game .zip file
  Extract .zip file
  Double left click "...CD.iso"
  Left click "Open"
  Left Click "DVD Drive (D:)..."
  Double Left Click INSTALL
  Left click "Yes" in Setup.exe
  Follow the defaults settings
  Game should work

**For Linux:**
  Install Proton
  Use Protontricks
  Use Procmon
  Mount the iso Instead of Extract (extractor breaking the file names by limiting them to 8 characters)
  Run the installshield wizard
    LearnGameLaunch.exe enters a loading screen then crashes
    JSWorldK.exe launches but blackscreens without crashing
  Editting the .ini files with the proper pathing fixed the issues of crashing immediately after character creation
